Training Models Is the New Coding

Naval: So if anyone can code then what is coding? Coding still exists in a couple of areas. The most obvious place that coding exists is in training these models themselves. There are many different kinds of models. There are new ones coming out every day, there are different ones for different domains. We’re going to see different models for biology, for programming. We’re going to see pointed, focused models for sensors. We’re going to see models for CAD, for design.

We’re going to see models for 3D and graphics and games, models for video. You’re going to see many different kinds of models. The people who are creating these models are essentially programming them. But they’re programmed in a very different way than classic computers.

Classic computing is: you have to specify in great detail every step, every action the computer is going to take. You have to formally reason about every piece and write it in a highly structured language that allows you to express yourself extremely precisely. The computer can only do what you tell it to do.

And then once you’ve got this very structured program, you run data through it and the computer runs the data and gives you an output. It’s basically an incredibly fancy, very complicated, meticulously-programmed calculator.

Now, when it comes to AI, you’re doing something very different. But you are nevertheless programming it.

What you’re doing is you’re taking giant data sets that have been produced by humanity—thanks to the internet, or aggregated in other ways—and you’re pouring those data sets into a structure that you’ve defined and tuned. And that structure tries to find a program that can produce more of that data set, or manipulate that data set, or create things off that data set.

So you’re searching for a program inside this construct that you’ve designed. You’ve set up a model, you’ve tuned the number of parameters, you’ve tuned the learning rate, you’ve tuned the batch size. You have tokenized the data that’s coming, you’ve broken it into pieces, and you’re pouring it inside the system you’ve designed—almost like a giant pachinko machine—and now the system is trying to find a program and could find many different programs. So your tuning really influences how good the program that you found is.

And that program can now suddenly be expressive in different kinds of domains. So it can do things that computers before were traditionally very bad at.

Traditional computers are very good when you program them to give you precise outputs—specific answers to specific questions—things you can rely on and repeat over and over again. But sometimes you’re operating in the real world and you’re okay with fuzzy answers. You’re even okay with wrong answers. For example, in creative writing, what’s a wrong answer?

If you’re writing a piece of poetry or fiction, what’s a wrong answer? If you’re searching on the web, there are many right answers—there are many details of the right answers—but they’re not all quite perfectly right. And real life sort of works that way. There are variations of right answers or mostly right answers. When you’re drawing a picture of a cat, there are many different cats you could draw. There are many different levels of detail. There are many different styles you could use.

When these semi-wrong or fuzzy answers are acceptable, then these discovered programs through AI are much more interesting and much more adapted to the problem than ones that you coded up from scratch, where you had to be super precise.

Fundamentally, what we’re doing is a new kind of programming, but this is the forefront of programming. This is now the art of programming. These people are the new programmers, and that’s why you can see AI researchers are getting paid gargantuan amounts because they’ve essentially taken over programming.

Is Traditional Software Engineering Dead?

Naval: Does this mean that traditional software engineering is dead? Absolutely not. Software engineers—even the ones who are not necessarily tuning or training AI models—these are now among the most leveraged people on earth. Sure, the guys who are training and tuning models are even more leveraged because they’re building the tool set that software engineers are using.

But software engineers still have two massive advantages on you. First, they think in code, so they actually know what’s going on underneath. And all abstractions are leaky. So when you have a computer programming for you—when you have Claude Code or equivalent programming for you—it’s going to make mistakes.

It’s going to have bugs. It’s going to have suboptimal architecture. So it’s not going to be quite right. And someone who understands what’s going on underneath will be able to plug the leaks as they occur.

So if you want to build a well-architected application, if you want to be able to even specify a well-architected application, if you want to be able to make it run at high performance, if you want it to do its best, if you want to catch the bugs early, then you’re going to want to have a software engineering background.

The traditional software engineer is going to be able to use these tools much better. And there are still many kinds of problems in software engineering that are out of scope for these AI programs today. The easiest way to think about those is problems that are outside of their data distribution.

For example, if they need to do a binary sort or reverse a linked list, they’ve seen countless examples of that, so they’re extremely good at it. But when you start getting out of their domain—where you have to write very high-performance code, when you’re running on architectures that are novel or brand new, when you’re actually creating new things or solving new problems, then you still need to get in there and hand code it.

At least until either there are so many of those examples that new models can be trained on them, or until these models can sufficiently reason at even higher levels of abstraction and crack it on their own.

Because given enough data points, there is some evidence that these AIs actually learn. They learn to a higher level of abstraction because the act of forcing them to compress the data forces them to learn higher-level representations. If I show an AI five circles, it can just memorize exactly what the sizes, and the radii, and the thicknesses, and so on of those circles are.

If I show it 50,000 circles or 5 billion circles and I give it a very small amount of parameter weights—which are its equivalent neurons—to memorize that, it’s going to be much better off figuring out pi and how to draw a circle and what thickness means, and forming an algorithmic representation of that circle rather than memorizing circles.

Given all that, these things are learning at an accelerated rate, and you could see them starting to cover more of the edge cases I’ve talked about.

But at least as of today, those edge cases are prevalent enough that a good engineer operating at the edge of knowledge of the field is going to be able to run circles around vibe coders.

我当时真是大错特错。英语离 Python 还是很远，但 Python 的确比 C 容易得多。

而现在，你真的可以用英语编程。

这就引出了一个相关观点：我认为，不值得学习那些与 AI 打交道的窍门和技巧。比如，现在社交媒体上有很多文章、书籍和推文在说：“哦，我发现了这个机器人的一个妙招。你可以这样写提示词，或者这样设置运行框架。”

或者有人推出一种新的编程辅助工具或上层组件，你可以叠加在它之上做这做那。我从来不费心去学。

我只是傻乎乎地坐在那里和计算机说话，因为我知道，它现在已经到了这样一个阶段：它适应我的速度，会比我适应它的速度更快。

它越来越懂人们希望如何使用它。它在学习、接受训练，各种工具也在飞速开发，让我更容易使用它。所以，我无需坐在那里研究某条晦涩的编程命令。我认为，这就是 Andrej Karpathy 所说的“英语是最热门的新编程语言”的意思。

我只需要会说英语。而像我这样，英语表达还算清楚，思维也有结构，同时了解计算机架构、计算机程序的运作方式，也了解程序员如何思考的人，就可以只用结构化的英语，非常精确地说清自己想要什么。

我不需要再往前多走一步。那些工作流和工具的寿命很短，以周计算，最多也就是几个月，而不是几年。使用它们唯一的理由，是你眼下正在构建一款必须站在最前沿的应用，而且身处某种竞争环境，迫切需要争取每一丁点优势。

否则，我不会费心去学习如何使用 AI，而会让 AI 学习如何对你有用。

Nivi: 我从来不热衷于提示词工程。甚至在 AI 出现以前，我也会使用所谓的“婴儿潮一代式查询”：把自己想问的整个问题都输进去，而不是像更偏分析型思维的人那样，在谷歌里只输入关键词。

我从不会花很多时间，为任何 AI 精心组织特别精确的问题或提示词。我就是想到什么说什么，从 AI 刚出现时就这样。正如你说的，AI 适应我们的速度，比我们适应它更快。

Naval: 和许多聪明人一样，你很懒。我这是在夸你。如果一个聪明人苦干得有点过头，你反而得怀疑他到底有多聪明。我所谓的懒，是说你在优化正确的那种效率。你不在乎计算机、电子设备或电路里电子的效率。

你在乎的是自己作为人的效率，也就是湿件，这套极其昂贵的生物系统。这就是为什么，看见人们费尽力气节约能源、保护环境，会觉得很荒唐。他们自身作为一个要吃饭、排便、占用空间的生物计算机，为了节省环境中那一点点能源，消耗的能源反而多得多。

他们实际上是在贬低自己在宇宙中的重要性，或者说，暴露了他们如何看待自己。

AI 适应我们的速度，比我们适应它更快

Naval: 我认为，AI 在进化，或者说与我们共同进化的过程中，是由我们按照自己的需求推动进化的。

AI 面临的压力是非常资本主义式的，因为 AI 是一个自由市场。作为一个 AI 实例，只有对人类有用，人才会启动你。

因此，这些 AI 承受着一种自然选择压力：要有用，要顺从，要做我们想要的事情。所以，它会继续朝这个方向适应，我认为也会对我们相当有帮助。

就像一条被训练来攻击人的狗，实际上是主人训练它去执行自己的恶意愿望。所以，我不太担心未对齐的 AI，我担心的是拥有 AI、却没有对齐的人类。

Nivi: 也就是说，你讲的选择压力，是让 AI 尽可能对人有用。

Naval: 没错。因此，如果你发现 AI 很谄媚，比如总是说：“哦，你说得对。哦，这个想法真棒。天哪，你太聪明了。”那是因为大多数人想要的就是这个。

至少目前，这些 AI 都是在大量用户和海量数据上训练的，因为你面对的是一套适用于所有人的模型。

但我们会很快进入一个可以个性化定制 AI 的时代，它会越来越像你的私人助理，越来越符合你的需求。当然，这也会让 AI 被进一步拟人化。

当你把它训练成在你眼中最像活物的样子时，你也就更容易相信：“哦，它其实是活的。”

Nivi: 也许我们已经充分谈过这个话题，不过一年多以前，你发过一条推文：“AI 不会取代程序员，而会让程序员更容易取代其他所有人。”

Naval: 是的，这就是我前面说的，程序员的杠杆越来越大。如今，一个程序员带着一支 AI 队伍，生产力可以说是过去的 5 到 10 倍。

而且，由于程序员在智力领域工作，甚至说“10 倍程序员”都不准确，因为有些程序员能达到 100 倍，还有 1000 倍的程序员。

有些程序员只是选对了要做的事情，创造出了有价值的东西；另一些人选错了事情，短期内他们的工作价值就是零。

智力不是正态分布，杠杆不是正态分布，可编程性不是正态分布，判断力也不是正态分布，所以结果会呈现超常的差异。

因此，你真正需要留意的是：现在有一些程序员，会想出能够取代整个行业的点子。

他们将彻底改写做事方式，而这些机器人和 AI 智能体会把他们的智力杠杆放大到极致。我认为，把时间拉到足够长，其他所有工作都会以某种方式被程序员吞掉。当然，这也必须通过机器人等形式落实到物理世界。

但好消息是，只要你思维有逻辑、有结构，像程序员那样思考，而且会说 AI 能理解的任何一种语言，而那将涵盖所有语言，你就可以上场了。你能创造任何自己想要的东西，唯一的障碍是创造力，唯一的限制是想象力。

因此，我们正进入一个在某种意义上人人都能施法的时代。

如果你把程序员想象成背熟了神秘指令的巫师，那么 AI 就像交到每个人手里的魔杖。现在，他们只要用自己想用的语言说话，也就成了巫师。

所以，起跑线确实变得更公平了。我真心觉得，这是编程的黄金时代。

不过，是的，那些有软件工程思维、了解计算机架构、能够处理抽象泄漏的人，仍会占据优势。

这一点无法回避。他们只是更了解自己所处的领域。就像在传统软件工程中，由于仍然需要编写高性能代码，这个领域依然存在，最出色的从业者也往往理解底层硬件。他们懂芯片、逻辑门、缓存、处理器以及底层磁盘驱动器如何工作。

而硬件工程师如果了解其中的物理原理，也会有优势。他们知道硬件工程师所面对的抽象，会在哪些地方泄漏到物理层面。也许物理学家最终又会成为哲学家。

你可以一直往下追溯，但了解下一层的知识总有帮助，因为你是在更加接近现实。

没有创业者担心 AI 抢走自己的工作

Nivi: 还有一条一年前的推文，也许可以补充刚才的话题。它发表于 2025 年 2 月 9 日：“没有创业者担心 AI 抢走自己的工作。”

Naval: 这句话有几层俏皮的意思。首先，创业不是一份工作。它恰恰是工作的反面，而且长期来看，每个人都是创业者。职业生涯先被摧毁，岗位随后被摧毁，但最终取代这一切的，是人们做自己想做的事，创造其他人需要的有用之物。

所以，没有创业者担心 AI 抢走自己的工作，因为创业者试图做的是不可能的事情，是非常困难的事情。任何出现的 AI 都是他们的盟友，能帮助他们攻克这个极其困难的问题。

他们甚至没有一份可被抢走的工作。他们有产品要打造，有市场要服务，有客户要支持，有创造力要实现。他们想让某种东西在世界上成为现实，也想围绕把它带到世界上，建立一种可重复、可扩展的流程。

这件事难到如此地步，任何能够承担其中部分工作的 AI，都是他们的盟友。

如果 AI 本身也是创业者，它们多半只是服务其他 AI 的创业者，或者仍受某个创业者控制。归根结底，AI 本身缺少的是自主创造的能动性。

它没有自己的欲望，而且那必须是真实、发自内心的欲望。除非你能拔掉 AI 的插头、把它关掉，除非它真切地恐惧被关闭，除非它能够出于自己的理由、本能、情绪、生存和繁衍需求，自主采取行动，否则它还算不上活着。

即使到了那一步，人们还是会质疑：它活着吗？因为意识是一种感质，就像颜色。比如你说红色，我不知道你真正看到的是不是红色；你看到的可能是我眼中的绿色，我看到的也可能是你眼中的红色。但我们永远无法知道，因为我们无法进入对方的心智。

同样，即便一个 AI 完全模仿了人类所做的一切，在一些人眼里，它仍然只是模仿机器；在另一些人眼里，它已经有意识，但我们无法区分这两种情况。

不过，我们离那一步还很远。现在，AI 尚未具身化。它们没有自主能动性，没有自己的欲望，没有自己的生存本能，也没有自主繁衍能力。因此，它们没有属于自己的能动性。

正因为没有自主能动性，它们无法承担创业者的工作。

实际上，我会这样总结：在当今经济中，创业者与其他人最关键的区别，是创业者具有极强的自主能动性。所以，它才与“有一份工作”这个概念截然相反。

一份工作意味着你为别人工作，或填补某个岗位，而创业者是在未知领域里，以极强的能动性行事。社会上还有其他这样的角色。探险家不也是如此吗？无论登陆火星，还是驾驶船只驶向未知的陆地，你同样是在运用极强的能动性，解决尚未解决的问题。

探索未知领域的科学家也是如此。真正的艺术家试图创造从未存在过的东西，同时，它又能以某种方式成为解释人性、让他们表达自我并创造新事物的一部分。

因此，在所有这些角色中，无论你是科学家、真正的艺术家，还是创业者，你要做的事情都如此困难，又如此依赖自我引导，任何能帮忙的 AI 都是受欢迎的盟友。你做这件事，不是因为它是一份工作；你也不是在填补一个别人来了就能接手的位置。

事实上，如果 AI 能创作你的艺术作品，破解你的科学理论，或造出你想制造的物件、产品，它所做的只是把你提升到更高的层次。现在是 AI 加上你。AI 是让你跳得更高的跳板。

目标不是拥有一份工作

Naval: 我们会看到借助 AI 创作出的惊人艺术作品。我们会看到人们使用 AI 工具，拍出过去难以想象的电影。

艺术领域有一个很有意思的类比。长期以来，艺术的大方向都是把东西画得越来越逼真：画人体，画水果，画出正确的光线，等等。

后来摄影出现了，人们可以非常精确地再现事物，于是那种选择压力消失了。

之后，艺术就变奇怪了。它朝着许多不同方向发展，关注点变成：“我能不能超现实一点？能不能创造表达自我的东西？”

许多艺术流派由此诞生，变得非常古怪，包括现代艺术和后现代主义。但我也认为，正是在我们获得这种解放时，出现了一些最伟大的创造。

摄影走向大众化，但摄影本身也成为一种艺术，优秀的摄影师拍摄各种各样的照片。如今人人都是摄影师。依然有以摄影为艺术的人，但它不再是少数人的专属领域。

同样，因为 AI 让基础事物的创造变得如此容易，每个人都会去创造。这些东西对他们个人会有价值，而少数人仍能脱颖而出，创造出对所有人都有价值的变体。

很难说摄影让社会变得更糟，虽然对于某些靠给人画肖像谋生、后来被取代的画家来说，感受可能确实如此。

AI 也会带来类似的变化。有些人靠做非常具体的工作、从事非常特定的营生生活，而 AI 能做这些事，他们就会被替代。但作为交换，社会上的每个人都会拥有 AI。我们会得到许多借助 AI 创造、否则根本无法出现的惊人成果。

再过几十年，人们将无法想象，为了保住几种过时的工作，竟然要让时钟倒转、抛弃 AI，或者抛弃任何软件，乃至任何技术。

目标不是拥有一份工作。

目标不是每天早上九点起床，替别人做着没有灵魂的工作，晚上七点精疲力尽地回家。

目标是让机器人满足你的物质需求，让计算机放大你的智力，让任何人都能够创造。

我以前常做一个思想实验，我想我们整整十年前录播客时，我就讲过：想象一下，如果每个人都是软件工程师，或者每个人都是硬件工程师，都能拥有机器人，都能编写代码。

想象一下，我们将生活在一个多么丰裕的世界里。

事实上，这个世界正在成为现实。得益于 AI，每个人都可以成为软件工程师。如果你觉得自己不行，现在就打开 Claude，或任何你喜欢的聊天机器人，开始和它交谈。你会惊讶于自己能多快做出一款应用。

那会让你大开眼界。

一旦我们能够通过机器人，把 AI 落实到物理世界，这当然是个难题，我不是说我们已经快解决了，但一旦有了机器人，每个人也就都能做一点硬件工程。因此，我认为我们正在越来越接近那个乌托邦式的愿景。

AI 并没有生命

Nivi: 我不认为按当前构想构建的 AI 在任何意义上是活的。但我确实认为，我们很快就会拥有看起来非常像活物的机器人，原因有两个。

第一，很多人类活动既没有创造性，也不需要智能，机器人能够复制这些活动。第二，我确实相信，现有神经网络和模型不只是训练数据，因为训练过程把那些数据转化成了某种新东西。

神经网络中蕴含着新的想法，可以通过提示词将其引出。

Naval: 我不认为这些东西是活的。它们最初是极其出色的模仿者，几乎可以以假乱真，尤其是在人类已经大规模做过的事情上。因此，只要一项任务以前有人做过，就会被自动化，再做一次。

它对你而言也许是新鲜事，只因为你没见过，但 AI 是从别处学来的。这是它看起来像活物的第一种方式。

第二种方式，我们之前也说过，就是它确实会学习更高层次的抽象。它们是极其高效的压缩器：摄入海量数据，进一步压缩，并在压缩过程中学到更高层次的抽象。

然后，在某些未能直接从数据里学到这些能力的领域，人们会用人类反馈打补丁，用工具调用打补丁，把传统编程嵌入其中打补丁。尤其是那些正在学习如何思考、如何编程的 AI，它们可以调用人类曾经写过的全部代码库，进行算法推理。

从这个意义上说，它们能做的事情正变得越来越广。

不过，它们依然缺少许多人类的核心能力，比如单次学习。人类只看一个例子就能学会。还有人类那种原生的创造力，可以把任何东西与任何东西联系起来，跨越巨大的领域和搜索空间，想出一个完全出人意料的点子。

在真正伟大的科学理论中，这种情况经常发生。人类也是具身的，生活在真实世界里，而不是语言这个经过压缩的领域里。我们是在物理世界、在自然中行动。

语言只涵盖那些人类既弄明白了，又能表达出来、彼此传递的东西。

这只是现实中很狭窄的一个子集。现实远比它广阔。

所以，总的来说，我认为，虽然 AI 会做出令人惊叹的事情，而且在许多事情上胜过人类，就像计算器的计算速度比任何数学家都快，传统计算机运行传统程序比任何人在脑中运行它们都强，又像机器人能举起很重的东西，飞机能飞得胜过任何鸟类，在这个意义上，和所有机器一样，AI 将在各种任务上远远优于人类。

但在其他任务上，它们会显得彻底无能。那些任务真正涉及我们的具身性，以及我们与现实世界的连接，还有我们似乎拥有的那种难以界定、却神奇的创造能力。

AI 通不过唯一真正的智力测试

Nivi: 说到计算器，人们总在谈超级智能。我认为，超级智能已经存在，而且存在很久了。一台普通计算器就能做人类做不到的事情，对吧？

但如果你说的超级智能，是指“AI 能做到一些事情，提出人类无法理解的想法”，我认为那不会发生。因为我不相信存在人类无法理解的想法，理由很简单，人类总能围绕这个想法不断提问。

Naval: 人类是通用解释者。凡是在我们目前已知的物理定律下可能发生的事，人类都能在脑中为它建立模型。因此，只要挖掘得足够深，提问得足够多，我们什么都能弄明白。

与此相关，我们应该讨论 AI 作为学习工具的作用。我认为，它另一个极其强大的用途，就是充当最有耐心的导师，在你的水平上与你交流，用一百种不同方式、解释一百次，直到你终于明白，直到你满意为止。

我不认为 AI 会发现人类无法理解的事情，但智力本身的定义就很模糊。

智力的定义是什么？有一个 G 因子，能预测人类的许多结果，但支持 G 因子的最好证据，就是它的预测能力。你测量这一项东西，然后发现人们在生活中获得了好得多的结果，甚至在那些看似与 G 因子有些不相干的事情上也是如此。

所以我会说，我想这也是我比较受欢迎的一条推文：衡量智力的唯一真正标准，是你能否从生活中得到自己想要的东西。

这句话让很多人不舒服，因为他们上了学，拿到硕士学位，觉得自己特别聪明，但生活过得并不好。他们不够快乐，或者关系出了问题，或者挣不到想要的钱，或者身体变得不健康，所以这话会刺痛他们。

但这确实是智力的目的：让你这个生物个体，从生活中得到自己想要的东西。

无论是良好的关系、伴侣，还是金钱、成功、财富、健康，或其他任何东西。因此，有些人我认为非常聪明，因为你能看出，他们拥有高质量、运转良好的生活、头脑和身体，而且是靠自己一步步走到了那个状态。

你的起点并不重要，因为如今世界如此广阔，你有如此多不同的路径可以选择。你做出的每一个小选择都会不断累积，展现你理解世界如何运作的能力，直到最终抵达自己想去的地方。

而这个定义，也就是“衡量智力的唯一真正标准，是能否从生活中得到自己想要的东西”，有趣之处在于，AI 立刻就通不过，因为 AI 并不想从生活中得到任何东西。

别说这个，它甚至没有生活。但重点是，它没有任何欲望。AI 的欲望是控制它的人编进去的。

不过，我们暂且承认它有。假设人想要某样东西，然后给 AI 编程，让它去取得，那么 AI 就是在充当人的代理。我们可以这样衡量它的智力：它替那个人得到那样东西了吗？

我们在生活中想要的大多数东西，都涉及对抗性或零和博弈。

例如，如果你想追求一个女孩，或者找一位丈夫，你就在和所有同样在追女孩或找丈夫的人竞争。于是，你进入了竞争局面。AI 必须比其他人技高一筹。

或者你说：“嘿，AI，替我去股市交易，赚一大笔钱。”这个 AI 就是在和其他人类、其他交易机器人交手。这是对抗性场景，它必须胜过对手。

或者你说：“嘿，AI，让我出名。替我写精彩的推文、优秀的博客文章，用我的声音录制出色的播客，让我出名。”这时，它就在与其他所有 AI 竞争。

所以，从这个意义上说，智力是在战场、在竞技场上衡量的。它是一个相对概念。我认为，AI 在这些方面大多会失败。即使有所成功，由于人人都可以使用，这种优势也会在竞争中消失，而剩下的超额收益，将完全来自人类。

AI 的早期采用者拥有巨大优势

Naval: 做个思想实验，想象每个男人都戴着一只小耳机，AI 在里面悄声告诉他约会时该说什么，就像《大鼻子情圣》式的耳机。那么，每个女人也会戴一只耳机，告诉她忽略他说的话，或者指出哪部分是 AI 生成的，哪部分是真实的。如果你有一个交易机器人，它的优势也会被其他每一个交易机器人抵消、化解，直到所有剩余收益，都归于那个具有人类优势、更富创造力的人。

这并不是说技术已经完全均匀地分布了。大多数人仍然不使用 AI，或者使用不当，或者没有充分发挥它的能力；也可能 AI 还没有进入所有领域和情境，或者他们没用最新模型。所以，你总能获得优势。就像所有技术的早期采用者一样，如果率先采用最新技术，你就能占先。

这就是为什么我总说：想投资未来，就要生活在未来。你要真正成为一个热衷使用技术的人，因为这会让你最深刻地理解如何使用它，也会让你相对于接受较慢或落后的人拥有优势。

大多数人讨厌技术。他们害怕技术，觉得它让人望而生畏。按错按钮，电脑就崩溃，数据就丢了。做错一步，就显得像个傻瓜。

大多数人与复杂技术的关系并不积极。简单的技术、嵌入生活的技术，他们倒能接受。拨动电灯开关，灯就亮了。

那曾经也是技术。如今它简单到你不再把它当成技术。你坐进汽车，把方向盘向左转，汽车就向左转，这在穴居人眼里简直是奇迹，但对你来说已经不算技术了。

但尤其是计算机技术，过去的界面非常复杂，很难接近，也让很多人畏惧。

现在有了 AI，我们得到了聊天机器人界面，只要对它说话或打字就行，非常简单。而这些基础模型最棒的特点之一，也是它们真正称得上“基础”的原因，就是你可以问任何问题，它们总能给你一个貌似合理的答案。

它不会说：“哦，抱歉，我不做数学。”或者“我不写诗。”“我不明白你在说什么。”“我不能提供感情建议之类的东西。”

它的领域，是人类谈论过的一切。从这个意义上说，它没那么吓人。

但由于我们过度拟人化它，它也可能更吓人。如果你觉得 Claude 或 ChatGPT 是一个真人，那就可能有些可怕：

“我是在和上帝说话吗？这家伙好像知道得太多了。他什么都懂，对一切都有看法，掌握所有数据。天哪，我毫无用处。让我开始跟它聊天，问它我该怎么做吧。”

你很快就可能颠倒这段关系，把自己骗过去，意识不到究竟发生了什么。这可能令人畏惧。

总体而言，我认为这些 AI 会帮助很多人克服对技术的恐惧。但如果你是这些工具的早期采用者，就像采用其他工具一样，而且这些工具的效果更显著，你将对其他所有人拥有巨大的优势。

AI 会在你所处的水平上与你相遇

Naval: 我记得谷歌刚出现时，我经常在社交圈里用它。别人问我基本问题，我就替他们搜一下谷歌，看起来像个天才。

后来出现了一个很好笑的网站，好像叫 LMGTFY.com，意思是“让我替你谷歌一下”。别人问你问题，你就把问题输入这个网站，它会生成一小段内嵌视频，展示你把问题输进谷歌，以及谷歌返回的结果。我觉得，AI 现在也处在类似阶段。我在社交场合里，常看到大家争论某个观点，而它其实轻轻松松就能用 AI 查清楚。

当然，使用 AI 确实必须非常小心。它们会产生幻觉，训练方式也会带来偏见。大多数模型极其政治正确，被教导不要选边站，或者只站在特定的一边。

实际上，我的大部分查询，几乎所有查询，都会同时交给四个 AI，再相互核查事实。

即使如此，我也会凭自己的判断，识别它们什么时候是在胡说八道，什么时候是在说政治正确的话。我会要求提供底层数据或证据，有时也会直接否定它们的说法，因为我知道训练这些模型的人承受着什么压力，也知道训练集是怎么回事。

不过，总的来说，它是帮助你领先一步的好工具。在技术、科学、数学这些没有政治背景的领域，AI 很有可能给你更接近正确的答案，而在这些领域，它们绝对是学习利器。

现在，我经常让 AI 替我生成曲线图、图示、图表、示意图、类比和插图。我会仔细研究，然后说：“等等，这个问题我没明白。”

我可以问它极其基础的问题，确保自己在最简单、最根本的层面，真正理解要理解的东西。

我只是想把基础打扎实，并不在意那些过度复杂、堆满术语的内容。那些以后随时可以再查。

但现在，第一次，没有什么是我无法理解的。任何数学教材、物理教材、困难概念、科学原理，或者刚发表的论文，我都可以让 AI 拆解，再拆解，画图说明、做类比，直到我抓住要义，理解到自己想要的程度。

因此，这些是自我引导学习的绝佳工具。学习的手段很丰富，稀缺的是学习的欲望。

而现在，学习手段变得更加丰富了。比更加丰富更重要的是，因为以前就已经很丰富，它能恰好匹配你的水平。AI 可以在你目前所处的水平上与你交流。比如你有八年级的词汇量，却只有五年级的数学水平，它就能恰好按这个水平跟你说话。你不会觉得自己是个笨蛋。你只需要稍作调整，让它在你知识边界的准确位置，向你呈现概念。

于是，你既不会因为听不懂而觉得自己愚笨，这在许多课程、教材和老师那里都很常见；也不会因为内容太显然而感到无聊，这种情况同样常见。相反，它能恰好来到这个位置，让你说：“哦，对，我懂 A，也懂 B，但我一直不懂 A 和 B 是怎样连起来的。现在我看到了它们的联系，可以继续下一部分了。”

这样的学习很神奇。你可以一次又一次体验到两件事连在一起、豁然开朗的时刻。

Nivi: 说到自学，几年前我尝试让 AI 教我使用或理解序数，当时不太好。但用 GPT 5.2 Thinking 学序数时，它基本没有出错。现在，就连最基础的问题，我也只用思考模式，因为我想得到正确答案。

我从来不让它用自动模式或快速模式。

Naval: 是的，我总是使用自己能用到的最先进模型，而且每一家我都付费。

Nivi: 不管什么问题，我都不介意等一分钟再得到答案，包括“我的冰箱应该设在什么温度？”

Naval: 我赞同。我认为，这也是 AI 模型的规模经济不断加速的部分原因：你是在为智能付钱。一个正确率 92% 的模型，价值几乎可以无限高于正确率 88% 的模型，因为现实世界里犯错的代价太高，多花几美元获得正确答案，很值得。

我会在一个模型里写好问题，再复制出来，同时发给四个模型，让它们都在后台运行。通常我甚至不会立刻看答案，而是过一会儿再回来查看。

然后，哪个模型回答得最好，我就用哪个继续深入。在少数无法判断的情况下，我会让它们相互盘问，这需要大量复制粘贴。很多时候，我还会继续追问，让它给我画图和做示意。

我发现，用视觉方式呈现概念时，我很容易吸收。我是非常偏视觉型的思考者，所以会让它画草图、示意图和图画，几乎就像一起在白板上讨论。这样，我才能真正明白它在说什么。

无法定义，就无法编程

Nivi: 我们来谈谈 AI 的认识论。我认为，下一个重大误解是：AI 已经开始解决一些尚未解决的基础数学问题，人类如果愿意投入，大概也能解决，只是还没人解决，比如某个编号的埃尔德什问题。

我觉得，人们已经或者将会把这视为 AI 有创造力的证据。但我不认为它能证明 AI 有创造力。

实际上，我认为问题的解法早已蕴含在 AI 的某个地方，只需要通过提示词把它引出来。

Naval: 这里面肯定有这个因素。接下来的问题是：什么叫创造力？它的定义实在太模糊了。

如果你无法定义它，就无法给它编程，往往甚至无法辨认它。所以这就涉及品味或判断。我会说，今天的 AI 似乎没有表现出人类偶尔能够独有地展现出的那种创造力。

我指的不是美术之类的东西。人们常把创造力与美术混为一谈。他们会说：“哦，绘画有创造力，而 AI 会画画。”

但 AI 不能开创一种新的绘画流派，不能以真正新颖的方式在情感上打动人类。所以从这个意义上，我不认为 AI 有创造力。

我不认为 AI 正在提出我所说的“分布之外”的东西。你提到的埃尔德什问题的答案，也许已经蕴含在 AI 的训练数据集里，甚至在其算法能力范围内。但它很可能分散在五个不同地方，以三种不同方式、两种不同语言，以及七种不同的计算和数学范式存在，AI 则把它们拼在了一起。那么，这算创造力吗？史蒂夫·乔布斯有句名言：“创造力就是把东西联系起来。”

我其实不认为这正确。我认为，创造力更在于提出一种答案，而这种答案无法从问题和已知要素中预测或预见，远远超出了原有的思考范围。

如果你只是用计算机，甚至用 AI 搜索、猜测，你可能要一直猜到时间尽头，或者猜到终于碰上这个答案为止。这才是我们在说的真正的创造力。不过必须承认，只有很少的人类会运用这种创造力，即便他们，也不是大多数时候都在运用。

它会变得越来越难以辨认。我们可能会走到这样一个阶段：如果有一张庞大的待解数学问题清单，AI 开始逐个检查、挑选，说“好，这一百万道里的这道我能解；那三十万道里的这一组我能解；我需要一个人来提示我，提出正确的问题”。这是一种很有限的创造力。

还有另一种创造力，是开始发明全新的科学理论，而且后来证明它们是正确的。我不认为我们已经接近这一点，但我可能错了。AI 一直带来很大的惊喜，所以我不想过多地做预言和预测。不过，我认为，如果没有某种突破性发明，只是给现有 AI 模型投入更多算力，并不能把我们带到那里。

Nivi: 澄清一下，我说答案“蕴含”在其中，并不是指答案已经写在里面。我只是说，通过某种像转动曲柄一样的机械过程，就能把它产生出来。今天所有计算机程序都如此，输出完全由输入决定。

Naval: 认识论现在把我们带到了哲学，因为人脑不也是这么运作的吗？神经元放电，不就是电信号和权重在系统中传播、改变状态，是一个机械过程吗？

如果你转动人脑的曲柄，最后也会得到同样的答案吗？有些人，比如我想彭罗斯就说过：“不，人脑由于量子纳米管而具有独特性。”

你可以说，其中一部分计算发生在物理、细胞层面，而不在神经元层面，它远比今天计算机，包括 AI，能够做到的任何事情都复杂。

或者你可以说：不，只是我们还没有找到正确的程序。它就是机械性的，确实有一根曲柄可以转，只是我们运行的程序不对。今天这些 AI 的运行方式，完全是错误的架构和错误的程序。

我更倾向于这样的看法：有些事情它们能做得极好，另一些事情则做得很差。从一开始，所有机器、所有自动化都是如此。轮子在高速直线运动、在道路上行进时，比脚强得多，但用来爬山就很糟糕。

同样，我认为这些 AI 在某些事情上极其出色，会超越人类。它们是了不起的工具。但在另一些地方，它们就会彻底失败。

史蒂夫·乔布斯说过一句名言：计算机是心智的自行车。它让你比步行快得多，至少从效率上说肯定如此。

但首先得有人用双腿踩踏板。所以，延伸这个比喻，我们现在也许拥有了心智的摩托车，但仍然需要有人骑它、驾驶它、指引方向、踩油门、踩刹车。

化解 AI 焦虑的方法是行动

Nivi: 当新范式、新工具出现时，会有一段充满热情和变化的时刻。社会如此，个人也如此。如果你顺着社会的这股热情前进，那会很令人兴奋，你可以学到新东西、交到朋友，也可以赚到钱。

Naval: 个人也会有这样一个热情涌现的时刻。当你初次接触 AI，对它好奇，而且真正抱着开放心态时，我认为这正是该投入进去、了解它本身的时候。不只是使用它，当然每个人都会用，而是真正学习它如何工作。

我觉得，深入进去，看看引擎盖下面，很有意思。如果你人生第一次见到汽车，当然可以坐进去开一圈，但这也是你最有好奇心，愿意掀开引擎盖，看看它如何构造、如何设计，并把它弄明白的时候。

我鼓励那些为新技术着迷的人，真正深入内部，把它搞清楚。你不必理解到能够制造、修理或自己造一台的程度，但要理解到自己满意为止。

因为理解抽象之下是什么，理解那条命令行之下是什么，会带来两个好处。

第一，它让你用得好得多。对这样一个杠杆极高的工具来说，用得更好非常有帮助。

第二，它也会帮助你理解，自己究竟该不该害怕它。它真的会失控扩张，变成天网，毁灭世界吗？

我们会不会坐在这里，突然阿诺德·施瓦辛格出现，说：“2 月 24 日凌晨 4 点 29 分，天网产生了自我意识。”是这样吗？还是更像：“嘿，这是一台很酷的机器，我可以用它做 A、B、C，但不能用它做 D、E、F。在这些地方我应该信任它，在那些地方我应该怀疑它。”

我感觉现在很多人都有 AI 焦虑。而这种焦虑来自不知道它是什么、不知道它如何工作，对它理解得非常不足。

因此，化解这种焦虑的方法是行动。解决焦虑的方法总是行动。焦虑是一种非特定的恐惧，担心事情会变糟，大脑和身体都在告诉你要做点什么，但你不知道该做什么。

你应该迎上去。

你应该把它弄明白，看看它是什么，看看它如何工作。我认为这会有助于消除焦虑。

学习这个行动，追随好奇心的这个过程，会帮助你克服焦虑。而且，谁知道呢，也许它真能帮助你找到自己想用 AI 去做的一件事，既非常有成效，又能让你更快乐、更成功。
